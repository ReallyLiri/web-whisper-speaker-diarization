# Web Whisper Speaker Diarization

[![Netlify Status](https://api.netlify.com/api/v1/badges/ed9b631f-bba7-4fd9-b85e-a3829e8ae3c9/deploy-status)](https://app.netlify.com/projects/web-whisper-speaker-diarization/deploys)

In-browser automatic speech recognition with word-level timestamps and speaker segmentation. No server required — everything runs locally in your browser using WebGPU or WASM.

Adapted from [Xenova/whisper-speaker-diarization](https://huggingface.co/spaces/Xenova/whisper-speaker-diarization).

## Development

```bash
npm install
npm run dev
```
